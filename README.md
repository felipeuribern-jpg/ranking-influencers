# Ranking mundial de influencia en redes

Paquete de arranque para Claude Code. Empieza por `CLAUDE.md`.

- `docs/` — especificación, fórmula, fuentes de datos, arquitectura, idiomas y plan.
- `docs/prototipo.html` — maqueta de referencia hecha en Claude.
- `data/influencers.json` — 40 perfiles reales (MX, ES, AR, CO) con seguidores de enero de 2026.
- `i18n/es.json` — textos base de la interfaz (se traducen en la fase 1).

Para empezar en Claude Code: abre esta carpeta y escribe
«Lee CLAUDE.md y empieza por la fase 0 del plan».
